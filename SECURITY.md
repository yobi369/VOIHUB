# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues or pull requests.

Use GitHub's **Private vulnerability reporting** feature for this repository when it is enabled. If private reporting is unavailable, contact the repository owner privately through an established channel and provide only the information needed to reproduce and assess the issue.

Include:
- A concise description and affected component.
- The impact and realistic attack scenario.
- Reproduction steps or a minimal proof of concept.
- Any suggested mitigation, if known.

Do not include real student records, personal information, API keys, access tokens, or other secrets in a report.

## Scope and response

VOI HUB handles learning profiles and classroom relationships, so reports involving unauthorized access to student or parent data, account takeover, assessment manipulation, or exposure of credentials should be clearly identified as high impact.

Please allow the maintainers reasonable time to investigate and prepare a fix before public disclosure. No response-time or service-level commitment is implied by this policy.
